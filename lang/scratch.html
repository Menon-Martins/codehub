🧩 Scratch — Learn From Zero

🎮Playground: Scratch Editor | Explore Projects — click, drag blocks, run.

What is Scratch?

Scratch is a visual programming language made by MIT. Instead of typing code, you drag and snap colorful blocks together — like digital LEGO. It's the friendliest way to learn how programming thinks, and it's perfect for kids and absolute beginners.

  • Animated stories & cartoons
  • Games (mazes, catch-the-ball, quizzes)
  • Music and art generators

Run Online — No Install

Go to scratch.mit.edu/projects/editor. No download, no account needed to try. Just drag blocks from the palette into the scripting area and click the green flag.

🟢 Beginner — Make a Sprite Move

The Green Flag

Every program starts with a when green flag clicked block (from the Events palette). Snap your other blocks underneath it.

Move & Say

From the Motion palette, drag move 10 steps. From Looks, drag say "Hello!". Click the green flag — the cat walks and talks.

blocks
when green flag clicked
move 10 steps
say "Hello!" for 2 seconds

Repeat (Loops)

Wrap blocks in a repeat 10 loop (Control palette) so they run many times.

blocks
when green flag clicked
repeat 10
  move 10 steps
  turn 15 degrees

🟡 Intermediate — Interaction & Variables

React to the Keyboard

Use when key pressed [space] (Events) to make things happen when the player acts.

Variables (Score)

Make a variable score (Variables palette). Increase it when the player catches something.

blocks
when green flag clicked
set score to 0
when sprite2 clicked
  change score by 1

If / Else

From Control, use if <touching mouse-pointer?> then to detect collisions.

🔴 Advanced — Broadcasting & Clones

Broadcast Messages

Send a message with broadcast "game over" so other sprites react at the same time.

blocks
when green flag clicked
broadcast "start game"

when I receive "start game"
  go to x: 0 y: 0

Clones

Use create clone of myself to spawn many enemies or raindrops without copying sprites by hand.

Custom Blocks

Define your own block with define jump to reuse a sequence of actions — like a function.
