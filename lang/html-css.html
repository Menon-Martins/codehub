What are HTML & CSS?

HTML (HyperText Markup Language) is the skeleton of every web page — it defines headings, paragraphs, images and links. CSS (Cascading Style Sheets) is the skin — it colors, spaces and lays out those elements. Together they build everything you see on the web.

  • Websites & landing pages
  • Blogs and portfolios
  • The base of React, Vue and every web framework

Run Online — No Install

Open CodePen or W3Schools Tryit. Type HTML on the left and CSS on the right — the result shows instantly. No downloads needed.

🟢 Beginner — Your First Page

Page Structure

html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello!</h1>
    <p>This is my first web page.</p>
  </body>
</html>

Tags come in pairs: <tag> ... </tag>.

Text & Links

html
<h1>Big Title</h1>
<h2>Smaller Title</h2>
<p>A paragraph of text.</p>
<a href="https://codehub.example">Visit CodeHub</a>

Use <a> for links and <img src="..."> for images.

Your First CSS

css
h1 {
  color: #4f46e5;
  font-family: Arial, sans-serif;
}
p {
  line-height: 1.6;
}

A rule has a selector (h1) and declarations (color: ...;).

🟡 Intermediate — Layout & Box Model

The Box Model

css
.card {
  width: 300px;
  padding: 20px;      /* inside */
  border: 1px solid #ccc;
  margin: 10px;       /* outside */
}

Every element is a box: content + padding + border + margin.

Flexbox

css
.row {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Flexbox lays items in a row and spaces them easily.

CSS Grid

css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}

Grid builds 2D layouts (rows + columns) like a spreadsheet.

🔴 Advanced — Responsive & Modern CSS

Media Queries

css
@media (max-width: 600px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Change layout on small screens (phones).

CSS Variables

css
:root {
  --brand: #4f46e5;
}
.btn {
  background: var(--brand);
}

Store values once, reuse everywhere.

Transitions & Animation

css
.btn {
  transition: transform 0.2s;
}
.btn:hover {
  transform: scale(1.05);
}

Smooth motion on hover and state changes.
